Setup required — Yard Flow needs a Supabase database to store your data. Follow these 3 steps:
STEP 1 — Create a free Supabase project
Go to supabase.com → Sign up (free) → New Project → give it any name → wait ~1 min for it to be ready.
STEP 2 — Run the database schema
In your Supabase project → SQL Editor → New query → paste the contents of schema.sql → Run.
STEP 3 — Add your API keys to this file
In Supabase → Project Settings → API → copy Project URL and anon public key. Open index.html in a text editor and replace:
const SUPABASE_URL = 'https://xxxx.supabase.co';
const SUPABASE_ANON_KEY = 'eyJ…your key…';
STEP 4 — Host it (optional but recommended)
Drag index.html onto netlify.com/drop for a free public URL that any staff member can visit from any device.
Once you've added your keys, refresh this page and you'll be ready to go.
